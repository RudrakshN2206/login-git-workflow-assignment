GIT COMMANDS USED

1. git init -b main
Creates a new local Git repository and names its starting branch main.

2. git config user.name 'Student Author'
Sets the initial placeholder author name. The commit history was later updated to the student's chosen author identity.

3. git config user.email 'student@example.com'
Sets the initial placeholder author email. The commit history was later updated to the student's chosen author identity.

4. git add index.html about.html
Stages the initial website files so they can be included in the first commit.

5. git commit -m 'Create initial two-page website'
Records the initial project state as the first commit.

6. git add index.html
Stages the homepage edit for the second commit.

7. git commit -m 'Update homepage description'
Records the homepage change as a separate commit.

8. git switch -c feature
Creates a branch named feature and switches to it.

9. git add about.html
Stages the feature branch change to the About page.

10. git commit -m 'Add feature project detail'
Records the feature change on the feature branch.

11. git switch main
Returns to the main branch before integrating the feature.

12. git merge --no-ff feature -m 'Merge feature into main'
Merges feature into main and preserves a visible merge commit in the history.

13. git add .gitignore
Stages the ignore rules for log files and the temp folder.

14. git commit -m 'Ignore log files and temp folder'
Records the .gitignore configuration in the repository history.

15. git add undo-demo.txt
Stages a temporary file for the undo demonstration.

16. git commit -m 'Add temporary undo demonstration note'
Creates the commit that will be undone.

17. git revert --no-edit HEAD
Safely undoes the latest commit by creating a new inverse commit; history remains intact.

18. git status --short --branch
Shows the current branch and whether the working tree has uncommitted changes.

19. git log --oneline --decorate --graph --all
Displays a compact graph of commits and branches, including the merge and revert.

20. git add git_commands.txt
Stages this command reference for inclusion or update in the repository.

21. git commit -m 'Document Git commands used'
Records the original command documentation in the repository.

22. git config user.name 'Rudraksh Nigotia'
Sets the final author display name for new commits.

23. git config user.email 'rudrakshnigotia_23ae057@dtu.ac.in'
Sets the email supplied by the student for commit attribution. This email is visible in public Git history.

24. git filter-branch --force --env-filter 'export GIT_AUTHOR_NAME="Rudraksh Nigotia"; export GIT_AUTHOR_EMAIL="rudrakshnigotia_23ae057@dtu.ac.in"; export GIT_COMMITTER_NAME="Rudraksh Nigotia"; export GIT_COMMITTER_EMAIL="rudrakshnigotia_23ae057@dtu.ac.in"' -- --all
Rewrites local branch history so every commit uses the student's selected author and committer identity.

25. git branch -avv
Displays local branches and the commit currently at each branch tip.

26. git remote -v
Displays the configured remote names and URLs.

27. git add git_commands.txt
Stages the final command log update.

28. git commit -m 'Document author setup and GitHub publishing commands'
Records the final author information and GitHub commands in the repository.
